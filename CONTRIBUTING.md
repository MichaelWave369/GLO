# Contributing to GLO Pin

GLO Pin should be genuinely useful on low-cost Android devices, over unreliable connections, and for people who don't want to identify themselves.

- Start with a specific problem and explain the observed behavior you want to improve.
- Open a PR for review and keep release claims tied to tests or field evidence.
- Do not introduce analytics, account requirements, trackers, silent remote calls, or automatic publication.
- Keep local observations separate from verified public resources and from inferred claims.
- Do not map people, sleeping sites, private homes, or sensitive locations.
- Do not label discarded food safe because a user reports no illness.
- New network adapters must disclose who receives requests and what data could be logged.
- Keep the web app independent of Peekaboo, Aidora, and other codebases.
- Preserve accessibility, reduced-motion, and low-bandwidth operation.

P0 offers no accountless online submission endpoint. GitHub may require accounts for code contributions, but use of the app never requires GitHub. Public community data will receive its own data license before a publishing service goes live.
